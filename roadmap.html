LONG-TERM PATH

기술 확장 방향

1단계

Foundation / Campus

ARP, Ethernet, VLAN/Trunk, STP/RSTP, LACP를 Packet과 장애 관점에서 다시 다집니다.

2단계

OSPF / Routing

Neighbor, LSA/LSDB, Cost, Area, Convergence, 장애 원인을 직접 구성·분석합니다.

3단계

BGP / VRF / FHRP

경로 정책, 네트워크 분리, Gateway 이중화와 Redistribution으로 확장합니다.

4단계

Edge / Cloud / DC

Firewall, NAT/VPN, WAN, AWS Network, Leaf-Spine, VXLAN/EVPN으로 이어갑니다.

공개 원칙: 학습 Evidence에는 개인 Lab용 주소와 가상/테스트 장비만 사용합니다. 회사의 실제 IP, Hostname, VLAN ID, SSID, 구성도, 로그는 공개하지 않습니다.
