네트워크 학습 여정

기술 목록이 아니라 패킷의 여정을 따라 학습합니다.

호스트가 목적지를 판단하는 기초부터 Campus LAN, 네트워크 서비스, Routing, 보안, Enterprise WLAN, 자동화, Cloud/Data Center까지 순서대로 연결합니다. 각 주제는 원리 이해에서 끝내지 않고 구성·정상 검증·장애 재현·복구·설명까지 남기는 것을 목표로 합니다.

읽는 순서: 처음 방문했다면 0단계부터 순서대로 보는 것을 권장합니다. 이미 알고 있는 기술도 패킷 흐름과 장애 원인을 자신의 말로 설명할 수 있는지 다시 확인합니다.
누적 학습 증거

실제로 검증한 내용만 집계합니다.

계획된 주제는 숫자에 포함하지 않고, Lab·Packet Capture·장애 재현·복구 검증처럼 확인 가능한 결과만 누적합니다.

—불러오는 중
현재 위치 · 0단계

네트워크 기초를 교육과정 순서로 다시 정리합니다.

ARP / Default Gateway는 검증과 설명 확인을 완료했고, Ethernet / MAC Table은 실습 완료 후 일부 개념을 복습하고 있습니다.

권장 다음 순서IP 주소 / Subnetting 교육 파일럿 → Ethernet / MAC Table 설명 복습 완료 → ICMP / Ping / Traceroute → VLAN / Access / Trunk
IP/Subnetting 연습 시작 →ARP / Default Gateway 학습자료 →Ethernet / MAC Table 학습자료 →
완료 기준

“구성할 수 있다”보다 “왜 그렇게 동작하는지 설명할 수 있다”를 기준으로 합니다.

정상 상태만 확인하지 않고 장애를 의도적으로 만들고, Packet·Log·상태 출력으로 원인을 좁힌 뒤 복구까지 확인해야 해당 주제를 완료한 것으로 봅니다.
