현재 집중확장 순서증거 기준
LEARNING ROADMAP

현재의 WLAN/NAC 운영 경험에서
전체 Enterprise Network를 보는 엔지니어로 확장합니다.

학습 목표는 기술 이름을 많이 아는 것이 아니라, 직접 구성하고 장애를 분석하며 왜 그렇게 동작하는지 설명할 수 있는 수준까지 깊이를 만드는 것입니다. 현재 강점인 Troubleshooting과 Network Automation은 새로운 기술을 익힐 때도 계속 결합합니다.

현재 집중 영역

Campus L2 + OSPF

이미 실무에서 접점이 있는 VLAN, STP, LACP, Access Switch 운영 경험을 이론·Lab·장애재현으로 보강하고, 그 위에 OSPF를 직접 구성·분석할 수 있는 수준으로 끌어올립니다.

목표

Enterprise Network Engineer

Campus LAN/WLAN, Dynamic Routing, Network Security 기본, Network Automation을 함께 다루며 문제 구간을 End-to-End로 판단할 수 있는 엔지니어를 목표로 합니다.

학습 원칙

깊이를 만드는 방식

01기술 이름보다 동작 원리

명령어 암기보다 왜 필요한지, 어떤 상태 변화가 생기는지 설명하는 것을 우선합니다.

02정상보다 장애 재현

정상 구성을 만든 뒤 일부러 실패 상황을 만들어 근거를 따라 원인을 좁힙니다.

03학습을 Evidence로

Topology, Config, CLI, Packet Capture, 자동화 결과를 GitHub에 남겨 재현 가능한 증거로 만듭니다.

성장 순서

기술 확장 로드맵

앞 단계의 이해가 다음 단계의 전제가 되도록 순서를 고정합니다.

1단계 · 현재

Campus L2 + OSPF

  • VLAN / 802.1Q / SVI
  • STP / RSTP / MSTP
  • LACP / Port-Channel
  • OSPF Neighbor / Area / LSA
  • Cost / ECMP / Convergence
2단계 · 다음

BGP + VRF / FHRP

  • eBGP / iBGP
  • AS_PATH / NEXT_HOP
  • LOCAL_PREF / MED
  • Prefix Filtering
  • VRF / Redistribution
  • VRRP / HSRP
3단계 · 중기

Edge / WAN

  • Stateful Firewall
  • ACL / NAT / Session
  • IPsec VPN
  • Dual ISP / Internet Edge
  • DHCP Relay / DNS / NTP / IPAM
  • SD-WAN 기본
4단계 · 장기

Hybrid Cloud / Data Center

  • AWS VPC / Route Table
  • TGW / VPN / Direct Connect
  • Leaf-Spine
  • Underlay / Overlay
  • VXLAN / EVPN / MP-BGP

완료 기준
