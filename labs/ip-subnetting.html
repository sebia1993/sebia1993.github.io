1단계 · CONCEPT GUIDE

IP 주소와 네트워크 나누기 Subnetting

네트워크 용어를 몰라도 괜찮습니다. 먼저 그림으로 “상대에게 바로 보낼지, 출구를 거쳐 보낼지”를 이해하고, 그 다음에 전문용어의 이름을 붙입니다.

오늘의 목표는 하나입니다.두 장치가 같은 네트워크 안에 있는지 판단하고, 다른 네트워크라면 왜 출구 역할의 장치를 거치는지 설명할 수 있으면 됩니다.
1 · 개념서 → 2 · 직접 확인
오늘 해결할 질문
내 컴퓨터는 상대에게 바로 보내야 할까?
아니면 다른 곳을 거쳐 보내야 할까?

이 질문에 답하기 위해 주소, 같은 그룹, 경계, 출구를 차례로 배웁니다.

00 · 먼저 상황부터

세 대의 컴퓨터가 있다고 생각해 봅시다.

아직 네트워크 전문용어는 외우지 않습니다.

01 · 주소

네트워크에서도 서로를 구분할 주소가 필요합니다.

집마다 주소가 있듯이, 네트워크에 연결된 장치도 통신할 때 사용할 주소가 필요합니다.
이런 주소를 → IP 주소라고 합니다.
02 · 같은 그룹

주소가 있다고 해서 모두 같은 네트워크에 있는 것은 아닙니다.

먼저 두 개의 “네트워크 동네”가 있다고 생각해 보겠습니다.

네트워크에서 이렇게 나눈 하나의 그룹을 → Subnet(서브넷)이라고 합니다.
03 · 경계

그런데 컴퓨터는 .127과 .128 사이가 경계라는 걸 어떻게 알까요?

주소의 앞에서 몇 bit까지를 네트워크 부분으로 볼지 나타내는 숫자를 → Prefix Length(프리픽스 길이)라고 합니다.
04 · 판단

이제 PC1 입장에서 두 목적지를 비교해 봅시다.

“직접 전달”은 케이블로 PC끼리 바로 연결한다는 뜻이 아닙니다. 같은 네트워크 안의 최종 목적지를 직접 전달 대상으로 본다는 뜻입니다.
05 · 다른 네트워크로 나가는 출구

다른 동네로 갈 때는 우리 동네의 출구를 먼저 이용합니다.

다른 네트워크로 나갈 때 기본으로 사용하는 Router의 주소 → Default Gateway
06 · 같은 경계를 쓰는 두 표기

/25와 255.255.255.128은 같은 경계를 다른 방식으로 적은 것입니다.

지금은 두 표현을 변환해서 외울 필요가 없습니다.

Prefix Length가 나타내는 같은 경계를 숫자 네 묶음으로 표시한 값 → Subnet Mask
07 · 선택 심화

궁금하면: 왜 이름이 하필 “/25”일까요?

같은/다른 그룹 판단을 이해했다면 이 부분은 나중에 펼쳐봐도 됩니다.

0과 1의 32자리로 /24와 /25의 차이 보기

지금 배우는 IP 주소 형식인 IPv4는 컴퓨터 내부에서 0과 1로 된 32개의 자리로 표현됩니다. 이 한 자리를 bit(비트)라고 합니다.

처음 학습에서는 이것만 기억하면 충분합니다. “/25는 32bit 중 앞 25bit를 네트워크 구분에 사용한다.” 복잡한 Binary AND 계산은 지금 외우지 않아도 됩니다.
08 · 한 번만 응용

경계 규칙이 바뀌면 같은 주소도 다르게 보일 수 있습니다.

09 · 오늘 새로 배운 말

이제 전문용어를 한 번에 정리합니다.

처음부터 외우는 사전이 아니라, 방금 본 그림에 이름표를 붙이는 복습입니다.

IP 주소

네트워크에서 장치를 구분하는 주소.

Subnet

같은 네트워크 범위로 묶인 하나의 그룹.

Prefix Length

주소의 앞에서 몇 bit까지를 네트워크 부분으로 볼지 나타내는 숫자. 예: /25는 앞 25bit가 네트워크 부분이라는 뜻.

Subnet Mask

Prefix Length가 나타내는 네트워크 경계를 숫자 네 묶음으로 표현한 값. 예: /25와 255.255.255.128은 같은 경계를 나타냅니다.

Router

서로 다른 네트워크 사이로 데이터를 전달하는 장치.

Default Gateway

내 네트워크 밖으로 갈 때 기본으로 사용하는 Router의 주소.

10 · REVIEW

여기까지 설명할 수 있으면 1단계 완료입니다.

⭐ 꼭 기억하세요

  • 장치는 네트워크에서 구분할 IP 주소를 사용합니다.
  • 주소는 같은 Subnet과 다른 Subnet으로 나뉠 수 있습니다.
  • /25는 이번 예제에서 .0~.127과 .128~.255라는 두 범위를 만듭니다.
  • 같은 Subnet이면 목적지를 직접 전달 대상으로 보고, 다른 Subnet이면 이번 예제에서는 Default Gateway를 이용합니다.
  • Subnet Mask가 달라지면 “같은 네트워크인가?”라는 판단 자체가 달라질 수 있습니다.
내 말로 설명하기

“PC1 .10이 PC3 .20에는 바로 보내고, PC2 .140에는 출구를 이용하는 이유는?”

전문용어를 꼭 쓰지 않아도 됩니다. 먼저 “같은 그룹 / 다른 그룹”이라는 말로 설명해 보세요. 그 다음 Subnet과 Gateway라는 용어를 붙이면 됩니다.
