Packet Filtering / ACL

R1—R2—R3의 Routing은 그대로 두고 R2의 ACL만 변경합니다. 먼저 결과를 예상한 뒤 Packet Stop 위치, ACE 순서, Direction과 hit를 확인하세요.

학습 기준: Policy Point → Match → Action. First Match / Implicit Deny / Interface Direction은 이 Lab에서 검증한 Cisco IOS ACL 구현 규칙입니다.
