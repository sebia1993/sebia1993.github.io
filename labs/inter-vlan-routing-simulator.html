Inter-VLAN Routing

결과를 먼저 예상한 뒤, Peer MAC인지 Gateway MAC인지, 그리고 Routing 전후 IP·TTL·Ethernet Header가 어떻게 달라지는지 확인합니다.

학습 기준: Off-link Packet은 L3 Gateway로 보내고 Router는 새 L2 Header로 Forward합니다. SVI는 이번 Cisco IOL에서 사용한 Gateway Interface 구현입니다.
1Next-Hop 예상같은 VLAN인지 다른 VLAN인지 먼저 판단합니다.
2실행ARP 대상과 Frame 경로를 확인합니다.
3비교IP·TTL·MAC과 장애 중단 지점을 연결합니다.
