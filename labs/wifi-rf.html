Wi-Fi / RF 기초

신호 세기와 잡음, 채널 사용 조건을 구분해 무선 품질을 설명합니다.

앞선 학습 · Stateful Firewall / IPsec VPN까지의 개념을 연결합니다.

01 · 질문과 그림으로 시작

Wi-Fi 신호가 강하면 언제나 통신 품질도 좋을까요?

30초 핵심 · 신호가 강한지만으로 품질을 판단하지 않습니다. 잡음과 얼마나 차이가 나는지, 같은 주파수 공간을 어떻게 함께 쓰는지도 확인해야 합니다.

02 · 방금 본 그림에 이름 붙이기

이름보다 역할을 먼저 기억하세요.

RSSI / Noise / SNR
수신 신호 세기, 잡음, 신호와 잡음의 차이입니다. dBm은 전력의 표현, dB는 여기서 두 값의 차이를 나타냅니다.
Band / Channel / Width
주파수 대역, 사용할 채널, 그 채널의 폭입니다. 폭이 넓으면 더 많은 주파수 공간을 사용합니다.
AP
단말이 Wi-Fi로 접속하는 장치인 Access Point입니다. 무선 통신에 사용하는 전파 특성을 RF라고 부릅니다.

03 · 동작 순서

핵심 흐름을 연결해 봅니다.

  1. 단말이 사용하는 대역과 채널을 확인합니다.
  2. 채널 폭이 차지하는 공간을 봅니다.
  3. 신호 세기와 잡음을 함께 보고 SNR을 구분합니다.
  4. 같거나 겹치는 채널의 사용 조건과 지역별 제약을 함께 확인합니다.

04 · 헷갈리는 지점

헷갈리는 의미를 구분해서 읽으세요.

구분뜻
같은 채널을 사용 · CCI 관련 조건같은 채널을 공유한다는 조건입니다. AP 수만으로 피해량을 측정한 것은 아닙니다.
인접·겹치는 채널 · ACI 관련 조건채널 할당이 겹칠 수 있는 조건입니다. 실제 간섭량·속도 저하는 별도 관측이 필요합니다.

05 · 복습

꼭 기억할 세 가지

  • RSSI와 SNR은 같은 값이 아닙니다.
  • 넓은 채널이 항상 실제 환경에서 빠른 것은 아닙니다.
  • 채널 배치와 실제 간섭 피해를 구분합니다.

Wi-Fi / RF 기초

목표는 하나입니다. RSSI 하나만 보고 품질을 판단하지 않고 Band·Channel·Width·SNR·간섭·DFS 조건을 함께 설명할 수 있으면 됩니다.

RF 품질은 “신호가 세다/약하다”보다 넓은 문제입니다.Band → Channel → Width → RSSI+Noise → SNR → Channel 관계 → DFS 순서로 봅니다.
1 · 개념서2 · Interactive Lab
Band → Channel → Width → RSSI + Noise → SNR → CCI / ACI → DFS

실측값이 없는 부분은 계산·공식근거와 실제 관측을 섞지 않습니다.

00 · 30초 핵심

무선 품질은 신호 세기 하나가 아니라 “신호 대 잡음 + 채널 사용 방식”입니다.

1

Band / Channel

먼저 2.4/5/6 GHz 중 어느 Band인지 확인해야 Channel 의미를 해석할 수 있습니다.

2

Width

20/40/80 MHz처럼 넓어질수록 더 많은 Spectrum을 묶어 사용합니다.

3

RSSI / SNR

RSSI는 Signal Power, SNR은 Signal과 Noise의 차이입니다.

4

CCI / ACI / DFS

같은 채널, 겹치는 채널, 규제 제약을 따로 구분합니다.

03 · CCI vs ACI

같은 Channel과 겹치는 Channel은 다른 문제입니다.

OBSERVED · 3차 보완 PASS

Co-Channel Condition

권한 허용 후 기존 CoreWLAN cache를 read-only로 확인한 보존 Snapshot MAC-AUTH-01에서 5 GHz ch149에 서로 다른 BSSID 4개가 기록됐습니다. 공유 자료에서는 AP-A / AP-06 / AP-12 / AP-13으로 익명화했습니다. 따라서 실제 same-channel condition은 확인됐지만, cache entry의 개별 나이·실제 동시 송신·처리량 저하는 측정하지 않았습니다.

04 · DFS

DFS는 5 GHz에서 Radar 공존을 위한 규제 조건입니다.

OBSERVED · KR

ch36/80 · ch149/80 → non-DFS 분류

이번 관측에서 본 5 GHz Primary ch36과 ch149의 80 MHz 그룹은 KR domain의 근거와 대조해 non-DFS로 분류했습니다.

NOT REPRODUCED

Radar Event / Channel Vacate

Radar Event는 관측하지 않았고, Channel Vacate도 재현하지 않았습니다. Radar를 생성하거나 Production AP Channel을 바꾸는 검증은 수행하지 않습니다.

주의: 사용 가능한 Channel과 DFS 범위는 Regulatory Domain에 따라 달라집니다. 특정 국가의 Channel 개수를 다른 국가에 그대로 적용하면 안 됩니다.
05 · REVIEW

다음 문장을 설명할 수 있으면 1단계 완료입니다.

⭐ 꼭 기억하세요

  • RSSI가 강해도 Noise가 높으면 SNR은 나빠질 수 있습니다.
  • Channel Width가 넓어지면 더 많은 Spectrum을 사용해 Reuse 선택지가 줄어듭니다.
  • CCI는 같은 Channel 공유, ACI는 겹치거나 인접한 Channel Allocation 문제입니다.
  • 관측되지 않은 RF 현상을 실측한 것처럼 쓰지 않습니다.
  • DFS는 Regulatory Domain과 함께 해석합니다.
