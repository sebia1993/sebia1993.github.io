보조 도구 · 자유 IP / CIDR 계산

실습 조건 · 기존 검증 근거

주소 계산은 저장소의 IPv4 계산 모듈을 사용합니다. /31은 Point-to-Point, /32는 Host Route 문맥입니다.

기존 네 가지 네트워크 시나리오는 Cisco 3725 IOS 12.4(15)T14 · VPCS 1.0 · PNETLab에서 확인한 2026-10-03 기록을 재사용합니다. R1의 Proxy ARP는 꺼져 있고 링크는 정상입니다. 초기 ARP 지연에 따른 ping 손실은 필수 규칙으로 모델링하지 않습니다.

기존 검증 요약Concept GuideRFC 1878RFC 3021
학습용 시뮬레이션입니다. 주소 계산에는 Packet을 사용하지 않으며, 전달 시나리오에서만 경로를 표시합니다. 브라우저 애니메이션은 실제 장비 검증 기록이 아닙니다. 새로고침·재진입하면 미응답 상태로 시작합니다.
