COMMON SCENARIOS

실제 운영에서 자주 다룬 사례

AUTH

Wi-Fi / 인증 실패

  • Access Tracker 확인
  • AD 계정 상태 확인
  • 사용자·단말 조건과 정책 일치 여부 확인
  • 계정·정책·단말 조건으로 실패 구간 분리
AP / CLIENT

접속 이상 / 속도 저하

  • AP 상태와 Association 확인
  • AP Hang 여부 확인 및 필요 시 재부팅
  • 클라이언트 무선 NIC 상태·드라이버 확인
  • 사용자 로컬 설정 오류 분리
SERVICE PATH

연결은 되지만 서비스 불가

  • WLAN/NAC/Access 영역 정상 여부 확인
  • Gateway/Session/목적지 경로 확인
  • Firewall Policy 여부 확인
  • 자체 영역 정상 근거와 함께 타 담당자 이관
