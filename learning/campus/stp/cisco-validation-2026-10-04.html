STP-01 · BPDU / Root Bridge Election PASS

Equal Priority 32768에서 STP 출력 전에 Base MAC을 확인해 SW1을 Root로 예측했습니다. 실제 MAC은 SW1 aabb.cc00.0100, SW2 .0200, SW3 .0300 순이었고 실제 Root는 SW1이었습니다. 이후 Base Priority를 24576/28672/32768로 바꾼 Deterministic Baseline에서도 SW1이 Root였습니다.

Equal operational priority 32778 · Baseline root priority 24586 · BPDU Root ID matched SW1 on L12/L23/L31

STP-02 · Loop-Free Port Role Map PASS

Baseline은 요청서와 정확히 일치했습니다. SW1은 Root라 Root Port가 없고 L12/L31 모두 Designated/FWD, SW2-L12는 Root/FWD, SW2-L23은 Designated/FWD, SW3-L31은 Root/FWD, SW3-L23은 Alternate/BLK였습니다. Warmed PC1→PC3 Flow는 L31 Direct Path만 사용했습니다.

Actual path: PC1 → SW1 → L31 → SW3 → PC3 · Ping 3/3

STP-03 · Alternate / Discarding PASS

SW3 Ethernet0/1(L23)은 Altn BLK였지만 CP2에서는 RSTP version 2 BPDU가 실제 관찰됐습니다. User Data Active Path는 L31이었고 PC3 Edge에는 요청당 하나의 Echo Request만 도착했습니다.

해석: Alternate/Discarding은 Cable Down이 아닙니다. User Data Forwarding에서는 제외되지만 STP Control Plane에는 참여합니다.

STP-04 · Path Cost Change PASS

SW3-L31 Cost만 4→20으로 변경하자 Direct Root Path는 20, SW2 경유 Path는 4+4=8이 됐습니다. SW3 Root Port는 L23으로 바뀌고 L31은 Alternate/BLK가 됐으며 실제 Data Path도 SW1→L12→SW2→L23→SW3로 이동했습니다.

Cost phase: CP1 + CP2 + CP4 request/reply · CP3 absent from active unicast path · Cost 4 recovery restored L31

STP-05 · Root-Port Link Failure Reconvergence PASS

SW3의 기존 Root Port L31을 shutdown하자 L23가 Root/FWD로 승격됐고 Data Path는 SW1→SW2→SW3로 자동 전환됐습니다. 연속 100개 Probe는 요청 100 / 응답 100 / 중복 Endpoint Request 0 / Missing Sequence 0이었습니다.

동일 PNET 게스트 Capture Clock 기준 마지막 Direct Delivery와 첫 Alternate Delivery의 간격은 0.201710초였습니다. 다만 Probe 간격이 200ms이므로 이는 관찰된 Data-Path Transition Delivery Gap이지 정확한 내부 Protocol Convergence Time이나 모든 RSTP 장비의 보편적 “0.2초 수렴”이 아닙니다.

last direct seq35 → first alternate seq36 · first failed Echo = NOT_OBSERVED · link recovery restored original direct L31 path

STP-06 · Root Priority Change PASS

SW3 Base Priority만 32768→16384로 낮추자 Root가 SW3(Operational 16394)로 변경됐습니다. SW1-L31과 SW2-L23가 Root Port가 되고, 차단 위치는 Baseline SW3-L23에서 SW2-L12 Alternate/BLK로 이동했습니다. SW3 Priority를 원복하자 Root SW1과 원래 Role Map이 복구됐습니다.

검증 한계

Rapid-PVST+ IOL 한 Run의 Actual입니다.

Classic PVST+/802.1D, MSTP, 물리 Catalyst Hardware의 성능을 비교하지 않았습니다. Altn BLK는 이번 Cisco Rapid-PVST+ CLI의 Alternate/Discarding 표현입니다.

Link Failure 때 IOL 한쪽 Interface shutdown이 반대편의 물리 Carrier-Down과 완전히 같다고 가정하지 않았습니다. Wire에 Frame 복사본이 보였다는 사실만으로 shutdown/Alternate Port가 User Data를 Forward했다고 판정하지 않고, Port Role/State + Endpoint Delivery + PCAP 상관관계를 함께 사용했습니다.
