# Ethernet / MAC Table Evidence

원본 PCAP 15개, 실험 콘솔/FDB, 보고서, GNS3 프로젝트(이미지 제외).

Python 3으로 `python3 verify-packets.py`를 실행하면 로컬 증거를 다시 판정합니다. 네트워크 접속이나 인증정보는 필요 없습니다.

프로젝트 가져오기에는 Docker 지원 GNS3 Compute와 alpine:3.23 이미지가 필요합니다. 새로운 프로젝트로 가져오며 기존 프로젝트를 덮어쓰지 마세요. 이식 대상 서버에서의 import 테스트는 아직 수행하지 않았습니다.

실행·검증은 Codex 대행이며 사용자 설명 확인은 대기입니다.
