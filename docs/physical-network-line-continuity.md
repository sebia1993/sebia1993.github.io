# 물리 네트워크 실습 — 연결선 연속성 수정

작업일: 2026-10-08. 기준 커밋: `2540de80b1af533172893ece69a0802a4393b557`.
대상: `labs/physical-network-simulator.html`의 연결과 영향 4문제.

## 결함과 원인

기존 CSS 가상 요소의 케이블 막대와 SVG 연결선이 서로 다른 끝점 좌표를 사용했다. 좁은 화면에서는 텍스트를 포함한 장비 상자의 경계까지만 연결해 실제 아이콘과 떨어졌고, 케이블 막대의 안쪽 여백과 연결선 끝점 사이에도 공백이 남았다. 넓은 화면에서도 케이블 막대 높이와 SVG 기준 높이가 달랐다. 정상 상태의 틈은 의도된 장애 표시가 아니다.

## 수정

- 구리 케이블 2개, 광 케이블 2개, 스위치와 확대 표시 지빅 사이 연결 2개를 각각 하나의 연속 SVG path로 그린다. 케이블 라벨은 장비로 취급하지 않는다.
- 끝점을 아이콘 내부의 명시적 접속 위치로 정하고, 화면 변환 좌표를 같은 SVG 좌표계로 환산한다. 접속 위치는 학습용이며 실제 장비 포트 번호/배치를 뜻하지 않는다.
- 중복 CSS 케이블 막대를 실습 범위에서만 제거한다. 선은 텍스트 전용 영역을 피해 배치하고, 배경에 가려지거나 버튼 클릭을 가로채지 않는다.
- 정상은 실선, 실제 분리/제거 상태에 해당하는 구간만 붉은 점선과 X 표시로 바꾼다. 단선 이후의 서비스 영향과 스위치/다른 AP의 전원 상태는 기존 모델을 유지한다.
- 모바일·태블릿 재배치, 화면 회전, 글자 확대, 출처 자료 묶음에서 연결 문제로 돌아올 때 접속 위치를 다시 계산한다. 중복 초기화와 불필요한 연속 redraw를 방지한다.
- 901px 부근에서 지빅 상태 문구의 줄 수가 바뀌어 아이콘 위치가 흔들리지 않도록 상태 영역 높이를 확보한다. 200% 글자 확대에서도 AP 연결선이 상태 문장을 가로지르지 않도록 글자와 선의 공간을 분리한다.
