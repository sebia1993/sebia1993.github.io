- 설명·공식 출처 펼침과 닫기, 키보드 Enter/Space 조작 정상
- 첫 포커스의 본문 건너뛰기, 목차 이동, 로드맵 왕복 정상
- 펼침 전후 가로 넘침 없음, 콘솔·페이지·요청 오류 0건
- 모바일 도식·표·본문과 데스크톱 주요 도식을 캡처해 잘림·겹침·라벨 가독성 확인
- 683×384 추가 검사에서 가로 넘침 없음. 이는 1366×768의 200% 확대에 해당하는 재배치 근사 검사이며, 브라우저 확대 UI를 직접 조작한 결과는 아님

화면 검사 상태 안내를 추가한 뒤에도 같은 네 viewport에서 로컬 재검사 **4개 조합 모두 PASS**였다. 추가 문단을 펼친 모바일·데스크톱 화면도 확인했다. 변경 후 공개 배포 검사는 아직 NOT_RUN이며, 기준 커밋의 공개 페이지 검사와 구분한다.

상세 상태와 실행 시각은 [JSON 기록](dc-fabric-browser-20261017.json)에 보존한다. 2026-10-13 정적 audit의 당시 미수행 상태는 변경하지 않았다.

## 실제 검증과의 경계

**DC-01~06의 실제 CLI·PCAP 검증은 NOT_RUN**이다. 화면 검사에서 PNETLab/Cisco 명령이나 패킷 캡처를 실행하지 않았으며, Windows 호환성 검증도 수행하지 않았다. 화면 PASS는 VXLAN/EVPN 또는 ECMP 동작의 PASS가 아니다.

학습 페이지의 초안 표시와 실습 준비 중 안내를 유지한다. 실제 결과는 [검증 상태 파일](../../results/dc-fabric.json)에 별도로 기록하며, 근거 검토 전 완료 상태로 승격하지 않는다.
