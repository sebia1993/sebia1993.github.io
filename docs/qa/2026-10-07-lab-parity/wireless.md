## 변경 사항

- 공통 ARP Shell과 공개 URL을 유지했다. 질문형 제목·주제별 시작 설명·힌트를 presentation에 분리했다.
- 일반 UI의 관찰/근거/범위/대기 등의 영어를 한국어로 표시했다. 실제 명령/로그/원본 근거는 보존하고 내부 데이터는 변경하지 않았다.
- RF는 전체 결과를 한 번에 공개하던 상태 화면을 각 문제 3단계로 분리했다. Width는 20 MHz 기준 1/2/4칸을 비교하고, SNR은 신호→잡음→차이의 계산 순서로 공개한다. RF에 패킷 이동을 억지로 추가하지 않았다.
- WLAN은 원본 메시지 순서를 그대로 유지하면서 PC A/AP A 사이에서 방향에 맞춰 Marker가 실제로 이동한다. 내부 상태·중단은 이동하지 않는다. 양방향 요약은 왕복 표현이다.
- 802.1X는 3장비 역할 그림과 함께 원인 사건·상태를 순서대로 공개한다. EAPOL과 RADIUS 구간을 구분한다. Reject/Timeout의 복구는 각각 별도 3단계로 원본 #416/#523와 Ping 3/3 근거를 사용한다.
- Roaming은 초기 조건→근거 대조→판단 범위를 공개한다. AP 그림은 관계를 보여주는 개념 표시이며 물리 이동 거리나 실측 시간으로 표시하지 않는다.
- 메시지 이동은 ARP의 420 ms/구간을 기준으로 하고, 도착 이후 설명 시간을 별도로 둔다. 일반 판단은 1470~1800 ms, 왕복 요약은 2070 ms이다. 모든 단계를 2490 ms로 고정하지 않는다.
- 메시지 그림은 좁은 화면에서 PC/AP/서버를 세로로 배치한다. 움직이는 Marker의 좌표를 실제 장비 배치에서 다시 계산하므로 가로 스크롤 없이 같은 방향 의미를 유지한다.

## ARP와 필요한 차이

RF/로밍 근거 검토는 패킷 전달 문제가 아니므로 상태·계산·근거를 주 관찰 영역으로 둔다. 802.1X는 학습 페이지와 같은 유선 실제 실습의 구성을 유지한다. WLAN 접속은 학습용 모델이며 공개 PCAP 및 사용자 장비 직접 실측의 범위를 구분한다. 장비명 표시만 대응시키고 원본 Evidence의 장비명/프레임 번호/해시는 그대로 보존한다.

## 실제 CI 캡처 육안 검수와 후속 수정

검토 자료: `/workspace/scratch/3ea555ad7246/qa/ci-final/guide-aligned-v2/`의 해당 4개 주제 캡처. 360·768·1366·1920px의 주 관찰 영역 16장을 원본 크기로 확인했고, 32개 초기/완료 전체 화면에서 상단·하단 조작 영역을 추출해 비교했다. 중간 관찰 영역은 앞의 원본 크기 캡처로 확인했다. 이 절의 육안 검토는 첫 문제의 캡처 범위이며, 전체 24문제의 기능 수행은 통합 CI 기록과 별도다.

발견 후 수정한 항목:

1. WLAN 메시지 기록 영역이 스크롤 위쪽에 머물러 최신 메시지의 아래쪽이 잘렸다. 현재 메시지가 표시되면 내부 목록만 마지막 행을 보여 주도록 변경했다. 페이지 전체는 자동 스크롤하지 않는다. 한국어 표시로 줄 수가 바뀐 후에도 현재 행을 확인하도록 적용했고, 이전 메시지는 위로 스크롤해서 복습할 수 있게 안내했다.
2. 802.1X의 768px 화면에서 숫자 열 120px가 메시지 본문 폭을 차지해 과도한 줄바꿈이 발생했다. 숫자 열을 28px로 줄이고 900px 이하에서 상태/메시지 패널을 한 열로 쌓았다.
3. WLAN 도착 Marker 일부가 장비 카드 뒤에 가려졌다. 연결선/Marker 층을 장비 위로 배치하되 클릭을 가로채지 않게 유지했다.
4. 802.1X 시작 조건에 남은 `SUPP↔SW1`, `SW1↔FreeRADIUS`와 역할 이름만 쓰인 첫 선택지를 표시 매핑으로 PC A–Switch A–Server A에 맞췄다. Roaming의 첫 선택지도 같은 PC A임을 표시했다. 원본 시나리오 해시는 수정 후에도 4개 모두 동일하다.

공통 Shell 전달 사항: 360px 캡처에서 고정 문제 탭이 관찰 그림·조작 영역 위에 겹치는 현상을 상위 작업에 전달했다. 공통 파일은 이 하위 작업에서 수정하지 않았다.

판정: 첫 캡처의 WLAN 현재 행/Marker와 802.1X 태블릿 폭 문제는 발견 후 수정했으며, 수정 후 화면 재캡처는 통합 QA에서 확인해야 한다. 그 외 검토한 관찰 영역의 PC A/AP A/AP B/Switch A/Server A 이름·한국어 카드와 연결 관계는 잘림 없이 확인했다. 일반 UI에 남은 영어 제목은 해당 범위에서 발견하지 않았고 EAPOL/RADIUS/STA/Authenticator 등 네트워크 용어는 유지했다.
